## Problem Statement

Suppose you are given the following code:
```csharp
class FooBar {
  public void foo() {
    for (int i = 0; i < n; i++) {
      print("foo");
    }
  }

  public void bar() {
    for (int i = 0; i < n; i++) {
      print("bar");
    }
  }
}
```

The same instance of `FooBar` will be passed to two different threads:
- thread `A` will call `foo()`, while
- thread `B` will call `bar()`.
Modify the given program to output `"foobar"` n times.

**Example 1:**
- **Input:** n = 1
- **Output:** "foobar"
- **Explanation:** There are two threads being fired asynchronously. One of them calls foo(), while the other calls bar().
"foobar" is being output 1 time.

**Example 2:**
- **Input:** n = 2
- **Output:** "foobarfoobar"
- **Explanation:** "foobar" is being output 2 times.

## Solution 1: Synchronization using Monitor

```csharp
using System.Threading;
using System.Threading;

public class FooBar {
    private int n;
    
    private readonly object _lock = new object();
    private bool _fooTurn = true; // Indicates it is Foo's turn first

    public FooBar(int n) {
        this.n = n;
    }

    public void Foo(Action printFoo) {
        for (int i = 0; i < n; i++) {
            lock (_lock) {
                // If it's NOT foo's turn, go to sleep and release the lock
                while (!_fooTurn) {
                    Monitor.Wait(_lock);
                }
                
                // printFoo() outputs "foo". Do not change or remove this line.
                printFoo();
                
                // Update the state so Bar can go
                _fooTurn = false;
                
                // Wake up all waiting threads (which will be the Bar thread)
                Monitor.PulseAll(_lock);
            }
        }
    }

    public void Bar(Action printBar) {
        for (int i = 0; i < n; i++) {
            lock (_lock) {
                // If it IS foo's turn, Bar must go to sleep and release the lock
                while (_fooTurn) {
                    Monitor.Wait(_lock);
                }
                
                // printBar() outputs "bar". Do not change or remove this line.
                printBar();
                
                // Update the state so Foo can go again
                _fooTurn = true;
                
                // Wake up all waiting threads (which will be the Foo thread)
                Monitor.PulseAll(_lock);
            }
        }
    }
}
```

**Detailed Explanation:**

- **The Shared Lock**: Both loops constantly try to acquire `_lock`. Only one can enter the critical section at a time.
- **The State Check**: When Bar() acquires the lock first, it checks `while (_fooTurn)`. Because _fooTurn is true, it knows it made a mistake. It calls `Monitor.Wait(_lock)`, goes to sleep, and gives the lock back.
- **Foo's Turn**: `Foo()` acquires the lock. It checks `while (!_fooTurn)`. Since _fooTurn is true, the loop skips. It prints "foo".
- **The Handoff**: `Foo()` changes `_fooTurn = false` and calls `Monitor.PulseAll(_lock)`.
- `PulseAll` wakes up `Bar()`. Once `Foo()` loops around and exits the lock (or hits Wait), `Bar()` re-acquires the lock.
- `Bar()` re-evaluates `while (_fooTurn)`. It is now false, so it prints "bar", flips the flag back to true, and pulses Foo().


## Solution 2: Synchronization using SemaphoreSlim

```csharp
public class FooBar {
    private int n;
    
    // fooSem starts with 1 permit because "foo" MUST go first.
    private SemaphoreSlim _fooSem = new SemaphoreSlim(1, 1);
    
    // barSem starts with 0 permits. It must wait for "foo" to release one.
    private SemaphoreSlim _barSem = new SemaphoreSlim(0, 1);

    public FooBar(int n) {
        this.n = n;
    }

    public void Foo(Action printFoo) {
        for (int i = 0; i < n; i++) {
            // Wait for permission to print "foo".
            // On the 1st iteration, it passes immediately (starts with 1).
            _fooSem.Wait();
            
            // printFoo() outputs "foo". Do not change or remove this line.
            printFoo();
            
            // Hand the baton to the Bar thread.
            _barSem.Release();
        }
    }

    public void Bar(Action printBar) {
        for (int i = 0; i < n; i++) {
            // Wait for Foo to hand over the baton.
            // On the 1st iteration, blocks until Foo() calls _barSem.Release().
            _barSem.Wait();
            
            // printBar() outputs "bar". Do not change or remove this line.
            printBar();
            
            // Hand the baton back to the Foo thread.
            _fooSem.Release();
        }
    }
}
```

**Detailed Explanation:**
1. Initial State: `_fooSem` has 1 ticket. `_barSem` has 0 tickets.
2. If `Bar()` starts first, it hits `_barSem.Wait()`. Because there are 0 tickets, it goes to sleep.
3. When `Foo()` runs, it hits `_fooSem.Wait()`. It takes the 1 ticket (leaving 0) and prints "foo".
4. `Foo()` then calls `_barSem.Release()`, putting 1 ticket into the Bar bucket.
5. This wakes up `Bar()`. It takes the ticket (leaving 0), prints "bar", and then calls `_fooSem.Release()`, giving the ticket back to Foo.
6. This cycle repeats `n` times.
