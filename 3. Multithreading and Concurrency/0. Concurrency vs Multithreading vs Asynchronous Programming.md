# Concurrency - Multithreading and Async Programming

Concurrency is the high-level concept of structuring a program to handle multiple tasks at the same time, 
whereas multithreading is a specific implementation of concurrency that uses lightweight execution units 
called **threads** to execute those tasks within a single process.

## Concurrency

Concurrency is about dealing with multiple tasks simultaneously. 
It allows a system to juggle multiple operations (like responding to user input, reading files, and waiting on network requests) 
without halting the entire program.
- **Mechanism:** It is often achieved through context switching or asynchronous programming (like an event loop).
- **Execution:** Tasks do not necessarily run at the exact same time. On a single-core processor, 
the CPU rapidly switches between tasks, creating the illusion of simultaneous progress.
- **Primary Goal:** Responsiveness and efficient resource management during "waiting" (I/O-bound) periods.

## Multithreading
Multithreading is a specific programming technique to achieve concurrency. 
It involves creating multiple threads within a single process, all of which share the same memory space.
- **Mechanism:** The operating system or runtime schedules these threads.
- **Execution:** On multi-core processors, threads can achieve actual parallelism (running at the exact same time).
On single-core processors, they run concurrently via context switching.
- **Primary Goal:** Task delegation and parallel execution to improve application performance and throughput.

## Key Differences at a Glance

| Feature | Concurrency | Multithreading|
| --- | --- | --- |
|NatureA | concept or structural property of a system. | A specific mechanism to execute tasks.|
|Focus|    How tasks are managed and structured.       |How tasks are executed.|
|Execution| Tasks overlap in time; can happen sequentially via switching.| Threads can run truly simultaneously on different CPU cores.|
|Resources| Can be implemented across multiple processes, machines, or a single thread.| Threads share the same memory space and resources of their parent process.|


## Asynchronous programming
Asynchronous programming (async) manages multiple tasks using a single thread, allowing it to pause and resume work 
while waiting for operations to finish. Multithreading spawns multiple workers (threads) to execute tasks simultaneously. 

**Async is ideal for I/O-bound tasks, while multithreading excels at CPU-bound tasks.** 

- **How it works:** Uses a single thread and an event loop to handle concurrency.
                    When a task hits a blocking operation (e.g., fetching data from a network or disk), the thread leaves
                    that task waiting and switches to process other tasks.
- **Resource efficiency:** Uses less memory and prevents the overhead of thread management and context switching.
- **Best used for:** I/O-bound jobs (like handling thousands of concurrent web requests, database queries, or API calls).
- **Syntax:** Often implemented using the async/await keywords.
